## About Contlo

Contlo is built for users who need smoother movement between devices without losing context. It focuses on practical synchronization tasks such as clipboard sharing, profile handling, and secure file exchange, while keeping the interface responsive and straightforward on Windows.

It also brings together automation and AI-assisted features in a way that can support everyday productivity setups. With offline-first operation and multilingual support, it is designed to stay usable in different environments and workflows, whether you are migrating settings, moving files, or coordinating work across devices.

## Features

- Real-time clipboard sharing across connected devices
- Encrypted peer-to-peer file transfer for direct exchange
- Profile migration support for moving settings and user data
- OpenAI and Claude integration for AI-assisted workflows
- Responsive UI designed for practical desktop use
- Offline-first operation for reduced dependency on constant connectivity
- Multilingual support for broader accessibility
- Cross-platform-oriented workflow design, with Windows as the primary target
